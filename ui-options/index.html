Four UI directions

Each direction is a real mockup layered over the running game: the fight behind every screen is a capture from the current build. Every option shows the same real information (health 92/100, a 22-hit combo at S rank, the Special Bar READY, wave 6, score 48,210, Fists equipped) across gameplay, the Special trace and QTE, title, loadout, pause with settings, results, and a states sheet. Gameplay is shown at desktop size (1280×720) and phone landscape (844×390).

Your choice

Reply with 1, 2, 3 or 4, or a mix, for example 1 for the HUD and 3 for menus. Nothing is built into the game until you choose.
